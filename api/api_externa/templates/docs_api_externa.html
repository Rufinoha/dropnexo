Como funciona

Vocês expõem endpoints REST HTTPS. O DropNexo faz pull periódico (e sob demanda) de produtos e estoque. SKU é a chave estável. Pedidos entram via webhook (em expansão).

Pull DropNexo → API de vocês (produtos / estoque / depósitos).
Push DropNexo → webhook de vocês (order.created / status).
Homologação Ambiente separado antes de produção, no card da integração.
Capacidades O fornecedor liga/desliga cada tarefa no painel.

Autenticação

HTTPS obrigatório. Escolha um dos modos no card da integração:

Authorization: Bearer <TOKEN>

# ou

X-Api-Key: <TOKEN>
UTF-8 JSON TLS 1.2+ Rate limit amigável

Webhook do parceiro

Informe a URL no card. O DropNexo envia eventos com assinatura HMAC no header X-DropNexo-Signature: sha256=<hmac>.

  • order.created
  • order.status_changed
  • order.canceled

Token DropNexo

Gerado no card da integração (mostrar uma vez). Use para endpoints inbound futuros e confirmações. Guarde com o mesmo cuidado do token do ERP.

Regras & boas práticas

  • SKU é a chave estável — não pode mudar.
  • Variação: informe sku_pai + atributos.
  • Paginação com next_cursor; sync incremental com updated_since.
  • Imagens em URL pública HTTPS.
  • Homologação antes de produção; logs no seu lado com SKU/pedido.
